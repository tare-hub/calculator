# Simple Calculator 🧮

A simple and user-friendly calculator built using **HTML, CSS, and JavaScript**. It performs basic mathematical operations with a clean and responsive interface.

## ✨ Features
- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Clear and delete functions
- Responsive user interface
- Real-time calculations

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started
1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Start calculating!

## 🎯 Purpose
This project was created to practice JavaScript fundamentals, DOM manipulation, event handling, and basic mathematical operations.
